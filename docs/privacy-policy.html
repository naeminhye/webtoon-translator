📖 Webtoon Translator

Privacy Policy

Effective date: February 1, 2026 · Last updated: July 15, 2026

Short version: your translation annotations and settings stay on your device. The developer operates no server and receives no data from you — ever. However, to translate text, the Extension does send the text being translated (and, for some optional features you enable, cropped panel images) to the translation service you choose, such as Google Translate or an AI provider you supply your own API key for. Nothing is sent anywhere until you use a translation feature.

1. Overview

Webtoon Translator is a Chrome browser extension that overlays translations on webtoon reader pages. This Privacy Policy explains what data the Extension stores, what data is sent to third-party services and when, and your rights as a user.

The developer of the Extension operates no backend server, has no user accounts, and receives no data of any kind from the Extension.

2. Data Stored Locally on Your Device

The Extension stores the following data in your browser's local extension storage (chrome.storage.local) and cache. This data stays on your device and is never transmitted to the developer:

  • Translation text you type or that a translation service returns
  • Bounding box coordinates (position of text on the panel image)
  • Text styling and display preferences (font, opacity, display mode, theme, UI language)
  • The webtoon title ID and chapter ID each annotation belongs to
  • Your settings, including the OCR engine choice and, if you configure one, your self-hosted OCR server URL
  • API keys you optionally enter for "Bring Your Own Key" (BYOK) AI translation. Keys are stored only in local extension storage and are only ever sent to the corresponding AI provider you chose them for
  • OCR confidence statistics (per-engine averages, counted locally)
  • Downloaded OCR/detection model files, cached in browser storage

If you use the Export feature, a JSON file containing your annotations is saved to your device. You are solely responsible for how you share that file.

3. Data Sent to Third-Party Services

The Extension has no server of its own. To perform translation, it talks directly from your browser to the service you select. Depending on your settings, the following requests occur:

3.1 Google Translate (default translation provider)

When a bubble is translated with the default provider, the recognized Korean text is sent to translate.googleapis.com and the translation is returned. Google's handling of this data is governed by Google's Privacy Policy. No account or API key is involved.

3.2 Chrome built-in translation (optional, on-device)

If you select Chrome's built-in Translator, translation runs on-device using models Chrome downloads from Google. The text being translated does not leave your browser.

3.3 BYOK AI providers (optional, off by default)

If you enter your own API key for OpenAI, Anthropic, or Google Gemini, then — for the requests where that provider is used — the text to be translated, and in the vision fallback case a cropped image of the specific speech bubble/panel region, is sent to that provider's API (api.openai.com, api.anthropic.com, or generativelanguage.googleapis.com) using your key. That provider's own privacy policy and API data-usage terms apply. If you never configure a key, no data is ever sent to these services.

3.4 Self-hosted PaddleOCR server (optional, off by default)

If you select the self-hosted OCR engine, cropped panel images are sent to the server URL you configure — by default http://127.0.0.1:8868, i.e. a server running on your own machine under your control. The developer has no access to it.

3.5 Model downloads from GitHub (optional)

If you download the in-browser OCR/detection models from the Settings page, the files are fetched from this project's GitHub Releases (github.com and GitHub's download CDN). This is an ordinary file download: no personal data is included in the request beyond what any HTTP request exposes (such as your IP address) to GitHub, per GitHub's Privacy Statement.

4. Data We Do NOT Collect

  • We do not collect your name, email address, or any personally identifiable information
  • We do not collect or store your browsing history
  • We do not use analytics, telemetry, tracking, or crash reporting of any kind
  • We do not sell, rent, or share any data with anyone — the developer never receives any data in the first place
  • The Extension does not read pages other than the supported webtoon reader pages it runs on

5. Permissions Explained

storage

Saves your annotations, settings, and locally computed OCR statistics on your device.

scripting, activeTab, offscreen

Used to inject the translation overlay UI into supported webtoon reader pages and to run OCR/detection models in a background document. The Extension only activates on supported webtoon sites.

Host permissions for webtoon sites and their image CDNs

Allow the overlay to run on the supported reader pages (Naver Webtoon, Kakao Page, Ridi, Bomtoon, Lezhin, Qtoon) and to load panel images for on-device OCR. The Extension does not modify page content — overlays are separate elements drawn on top.

translate.googleapis.com

The default translation provider (Section 3.1).

github.com and GitHub download CDNs

Fetching optional OCR/detection model files you request from Settings (Section 3.5).

Optional host permissions (requested only if you enable the feature)

api.openai.com, api.anthropic.com, generativelanguage.googleapis.com — BYOK AI translation (Section 3.3). 127.0.0.1 / localhost — your self-hosted OCR server (Section 3.4). Chrome asks for your consent when you enable these features; they are not granted at install time.

6. Data Retention & Deletion

All Extension data lives in your browser's local storage until you:

  • Delete annotations or reset stats from the Extension's own UI
  • Remove downloaded models from Settings
  • Uninstall the Extension (removes all stored data)

Data sent to a third-party translation service is retained according to that service's own policy; the Extension has no control over it.

7. Children's Privacy

The Extension does not knowingly collect data from children under 13. It contains no features directed at children and collects no personal information from any user regardless of age.
