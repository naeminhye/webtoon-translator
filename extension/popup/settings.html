Setup guide — run the PaddleOCR server locally ▾
  1. Download the files below into an empty folder.
  2. Install Python 3.9–3.12, open a terminal in that folder, then run: pip install -r requirements.txt
  3. Start the server: python server.py First run downloads ~30–60 MB of Korean OCR models — this can take a minute.
  4. Set the server URL above (default http://127.0.0.1:8868 already matches — leave the field empty).

CPU-only works fine, no GPU required — but PaddlePaddle inference is memory-hungry at startup; 4 GB+ RAM recommended for smooth performance (a rough estimate, not a benchmarked figure).

Prefer Docker? Download the Dockerfile too, then: docker build -t webtoon-paddleocr .
docker run --rm -p 8868:8868 webtoon-paddleocr

⬇ server.py ⬇ requirements.txt ⬇ Dockerfile ⬇ README.md

The server binds to 127.0.0.1 by default (not reachable from other devices) and has no built-in authentication — keep it that way unless you trust your local network.
